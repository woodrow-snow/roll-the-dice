# Overview
This app allows users to random pick a game from a list of 15 default games and the ones they add. To use this app, you will need to download the code base and the "Expo Go" Moblie app. Open the code in your editor of choice and run ```npm start```. This will start a server to host the app. Once everything is ready to go, scan the provided qr code in the terminal to launch the app through expo go.

I created this app to learn the development process of creating moblie apps using Expo and React Native
